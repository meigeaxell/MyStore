# MobileStore Scanner (Android)

Беспроводной Android-компаньон для настольного приложения **MobileStore**.  
Работает полностью локально по Wi-Fi (без интернета и облачных сервисов) через встроенный WebSocket-сервер MobileStore (`docs/MOBILE_PROTOCOL.md`).

## Возможности
1. **Сканер / Продажи**: постоянно активная камера (CameraX + ML Kit Barcode + ML Kit OCR для 15-значных IMEI с проверкой Luhn), без кнопки «Сканировать». Автоматическая пауза при открытии карточки товара, ввод выторгованной цены (USD/TMT), отправка в текущую продажу на компьютер.
2. **Приёмка**: выбор или быстрое создание товара, потоковое сканирование партии IMEI с проверкой дубликатов, подтверждение OCR-распознавания, автосохранение незавершённой приёмки в локальной базе Room.
3. **Каталог**: просмотр, поиск по названию/SKU/IMEI, просмотр устройств на складе, создание и редактирование карточек товаров.
4. **Категории**: создание, переименование и безопасная деактивация категорий.
5. **Настройки и подключение**: IP компьютера, порт, 6-значный PIN-токен, имя устройства, авто-переподключение и heartbeat.

## Сборка и установка на смартфон (Android Studio)
1. Откройте папку `android_scanner/` в **Android Studio** (Ladybug / 2024.2+ с JDK 17).
2. Дождитесь синхронизации Gradle (используется Gradle Kotlin DSL + Version Catalog `gradle/libs.versions.toml`).
3. Подключите Android-смартфон (Android 8.0+ / API 26+) по USB с включённой отладкой по USB (или соберите APK через **Build → Build Bundle(s) / APK(s) → Build APK(s)**).
4. Запустите приложение и перейдите во вкладку **Настройки**:
   - На компьютере откройте MobileStore → **Настройки** → **📱 Мобильный сканер (Android)**.
   - Введите на смартфоне локальный IP-адрес компьютера, порт (по умолчанию `8765`) и 6-значный PIN-код.
   - Нажмите **Сохранить и подключиться**.

> Если смартфон не подключается, убедитесь, что ПК и телефон в одной Wi-Fi сети, а входящий TCP-порт `8765` разрешён в брандмауэре компьютера.
