================================================================================
MOBILESTORE — ОПИСАНИЕ, ВОЗМОЖНОСТИ, ИНСТРУКЦИЯ И ШПАРГАЛКИ ПОЛЬЗОВАТЕЛЯ
================================================================================

Язык интерфейса приложений: упрощённый магазинный туркменский (латиница)
Назначение: учёт розничного магазина смартфонов, техники и аксессуаров
            (склад с IMEI и штрихкодами, мультивалютные закупки и касса USD/TMT,
            Trade-in, долги, финансы, аналитика прибыли, OCR коробок аксессуаров
            и мобильный Android-сканер).


--------------------------------------------------------------------------------
1. ОБЩЕЕ ОПИСАНИЕ И ТЕХНИЧЕСКИЕ ХАРАКТЕРИСТИКИ
--------------------------------------------------------------------------------

MobileStore состоит из двух приложений в локальной Wi-Fi сети (интернет не нужен):

1) Основная программа на ПК (Desktop POS / ERP):
   - Python + PySide6 (Qt), SQLAlchemy, локальная БД SQLite (WAL, foreign_keys=ON).
   - Хранение данных: `data/mobilestore.db` и `backups/` рядом с `MobileStore.exe`.
   - Автоматические миграции БД (Alembic) при запуске — при обновлении программы
     структура базы обновляется сама, без потери старых данных.
   - Встроенный локальный WebSocket-сервер (порт `8765`) для Android-смартфонов.
   - Печать чеков, Z-отчёты (`Z-hasabat`), экспорт в PDF и CSV.
   - Динамический (живой) поиск во всех разделах + автоматическая транслитерация
     раскладки клавиатуры для USB-сканера штрихкодов.

2) Мобильное приложение-компаньон (Android Scanner APK):
   - Kotlin + Jetpack Compose + CameraX + Google ML Kit (штрихкоды + OCR).
   - Подключение к ПК по Wi-Fi (IP, порт `8765`, 6-значный PIN).
   - Умеет:
     * сканировать IMEI / S/N / штрихкоды для продаж и приёмки;
     * распознавать коробки аксессуаров без штрихкода через **Aksessuar OCR / Guty OCR**
       (самообучаемые алиасы коробок + автозаполнение карточки нового товара);
     * работать с каталогом (включая поле «Ştrihkod / Barcode») и категориями.


--------------------------------------------------------------------------------
2. КАК БЕЗОПАСНО ОБНОВЛЯТЬ ПРИЛОЖЕНИЕ БЕЗ ПОТЕРИ БАЗЫ ДАННЫХ
--------------------------------------------------------------------------------

ВАЖНОЕ ПРАВИЛО: вся ваша база данных и история хранятся ТОЛЬКО в двух папках
рядом с `MobileStore.exe`:
  • `data/`     — рабочая база `mobilestore.db`
  • `backups/`  — резервные копии базы

Способ 1 — Автоматически внутри программы (рекомендуется на Windows):
  1. Скачайте свежий `MobileStore-Windows-x64-vX.Y.Z.zip` из GitHub Releases.
  2. Откройте в MobileStore: **Sazlamalar → Ätiýaçlyk nusga we bazany dikeltmek**.
  3. Нажмите кнопку **«⬆ Programmany täzele (ZIP)»** и выберите скачанный ZIP.
  4. Программа сама:
     - создаст страховочную копию `backups/pre_update_YYYYMMDD_HHMMSS.db`;
     - закроется, обновит `MobileStore.exe` и `_internal/`;
     - **НЕ тронет `data/` и `backups/`**;
     - автоматически запустится заново и применит новые миграции БД.

Способ 2 — Вручную (если обновляете руками):
  1. Закройте `MobileStore.exe`.
  2. На всякий случай скопируйте папку `data/` в надёжное место.
  3. Удалите в рабочей папке всё, КРОМЕ папок `data/` и `backups/`.
  4. Распакуйте туда содержимое нового ZIP-архива (`MobileStore.exe`, `_internal/`,
     `USER_GUIDE_AND_OVERVIEW.txt`).
  5. Запустите `MobileStore.exe` — все товары, кассы, чеки и настройки на месте.

3. ОСНОВНЫЕ ВОЗМОЖНОСТИ ПРИЛОЖЕНИЯ (ПО РАЗДЕЛАМ ПК)
--------------------------------------------------------------------------------

1) Esasy panel (Главная панель — Ctrl+1)
   - Выручка, прибыль, продажи, остатки касс, долги, предупреждения о низких остатках.

2) Harytlar we sklad (Товары и склад — Ctrl+2)
   - Каталог товаров с выделенным полем **«Ştrihkod (Barcode)»** (для приёмки и
     продаж аксессуаров по количеству), SKU, брендом, моделью и минимальным остатком.
   - **Полноценное редактирование IMEI-устройств (`StockItem`)**:
     откройте карточку товара (двойной клик или «📱 Haryt karty we enjamlar») →
     выделите нужный IMEI и нажмите **«✏ Saýlanan enjamy üýtget»** (или дважды
     кликните по строке IMEI). Можно менять IMEI 1, IMEI 2, S/N, модель (переносить
     на другой товар), состояние (`Täze`/`B/U`), статус (`in_stock`/`sold`/`written_off`),
     источник, себестоимость, валюту, курс и примечание. Остатки склада пересчитаются
     автоматически! Ошибочно добавленный IMEI можно удалить кнопкой **«🗑 Enjamy poz»**.
   - **Архивация товаров (даже если на складе есть остатки!)**:
     в карточке товара или кнопкой **«📦 Arhiwe geçir / ♻ Dikelt»** под таблицей
     можно заархивировать любой товар, даже если на складе есть остаток или IMEI.
     История и остатки сохраняются, товар просто скрывается из активных продаж.
     Чтобы посмотреть архив и вернуть товар обратно — выберите в фильтре статуса
     **«📦 Arhiwdäki harytlar»** и нажмите **«♻ Dikelt»**.

3) Alyşlar (Закупки — Ctrl+3)
   - **Приёмка товаров по количеству по штрихкоду**:
     в окне «Täze alyş» над таблицей товаров есть специальное поле
     **«Ştrihkod (Barcode) ýa-da SKU skan et / ýaz»**.
     Сканируйте USB-сканером (или введите штрихкод и нажмите Enter):
     - если товар найден и уже в списке → его количество автоматически станет **+1**;
     - если товара ещё нет в списке → он добавится с последней ценой закупа;
     - если штрихкод новый и его нет в базе → программа сама предложит создать
       новую карточку с уже заполненным полем «Ştrihkod» и сразу добавит в закупку!
   - Для смартфонов: ввод IMEI 1 / IMEI 2 / S/N вручную, USB-сканером или с Android.
   - Мультивалютные оплаты (USD/TMT), долги поставщикам, отмена закупок и возвраты.

4) Satyş we kassa (Продажи и касса — Ctrl+4)
   - **Динамический (живой) поиск**: при вводе названия, штрихкода, SKU или IMEI
     прямо под строкой поиска сразу появляется список совпадений (без нажатия Enter),
     клик добавляет товар в чек. При сканировании USB-сканером (с Enter) товар по
     штрихкоду или IMEI по-прежнему добавляется мгновенно!
   - Приём позиций с Android-сканера (включая OCR коробок аксессуаров с подсказкой
     последней цены продажи).
   - Свободный торг (`F4`), смешанная оплата USD + TMT, продажа в долг, отложенные
     чеки (`Ctrl+H`), печать чека / PDF, история и отмена чеков.

5) Trade-in (Обмен и выкуп Б/У — Ctrl+5)
   - Обмен старого телефона клиента на новый с доплатой или прямой выкуп Б/У в склад.

6) Maliýe (Финансы и кассы — Ctrl+6)
   - **Общая сумма всей кассы**: вверху экрана постоянно отображается синяя плашка
     **«💰 Jemi kassa (USD + TMT)»** — суммарные деньги обеих касс, пересчитанные по
     текущему курсу сразу в **TMT** и в **USD**.
   - **Просчёт всей кассы по купюрам**: кнопка **«🧮 Kassany sana»** открывает
     калькулятор купюр (номиналы TMT: `500, 100, 50, 20, 10, 5, 1` и USD: `100, 50, 20, 10, 5, 1`
     + мелочь) — считает реальные наличные, сравнивает с программой и позволяет
     в 1 клик выровнять кассу («⚖ Kassany sanalan pula deňle»).
   - **Сверка и закрытие смены**: кнопка **«🔒 Smenany ýapmak / Barlag»** (уже была в
     программе) — сверяет остатки за смену и сохраняет `Z-hasabat` в PDF.
   - **Обнуление кассы (изъятие выручки)**: кнопка **«🧹 Kassany nolla»** обнуляет
     кассу TMT, USD или обе сразу до `0.00` с обязательной записью причины в журнал.
   - **Погашение и обнуление долгов в 1 клик**:
     во вкладках **«Müşderiler bilen hasaplaşyk»** и **«Üpjün edijiler bilen hasaplaşyk»**:
     * **«✔ Doly hasaplaş (kassa)»** — полностью закрывает долг с проведением денег
       через кассу (уже существовало через открытие чека/закупки, теперь доступно
       ещё и одной кнопкой);
     * **«🧹 Bergini nolla»** — списывает/обнуляет долг **без движения денег в кассе**
       (например, взаимозачёт, прощение долга или исправление старой записи).
   - Расходы (`+ Çykdajy ýaz`), корректировки (`Düzediş / Storno`), журнал операций.

7) Hasabatlar (Отчёты — Ctrl+7)
   - 7 отчётов (`Satyşlar`, `Peýda (COGS)`, `Harytlar`, `Enjamlar (IMEI)`,
     `Sklad hasabaty`, `Üpjün edijiler`, `Müşderiler`) с экспортом в CSV.

8) Sazlamalar (Настройки, бэкапы, обновление и сканер — Ctrl+8)
   - Профиль магазина, курс, автобэкап, проверка и восстановление БД,
     **«⬆ Programmany täzele (ZIP)»** и настройки Wi-Fi сервера Android-сканера.


--------------------------------------------------------------------------------
4. ПОЛНЫЙ ЦИКЛ КУПЛИ-ПРОДАЖИ (КРАТКИЙ ПЛАН)
--------------------------------------------------------------------------------

1. Настройка («Sazlamalar»): название магазина, курс USD/TMT, папка бэкапов,
   подключение Android-сканера по Wi-Fi (IP + порт 8765 + PIN).
2. Создание товара («Harytlar we sklad» или Android «Kabul ediş → Guty OCR»):
   указываете категорию, бренд, модель и (для аксессуаров) **Ştrihkod (Barcode)**.
3. Закупка и приёмка («Alyşlar» или Android «Kabul ediş»):
   - для аксессуаров: сканируете штрихкод в поле «Ştrihkod skan et» (+1 шт. за скан)
     или «Guty OCR» на телефоне;
   - для смартфонов: сканируете/вводите IMEI 1 / IMEI 2 / S/N.
   Оплачиваете сразу или оставляете в долг поставщику.
4. Продажа («Satyş we kassa» + Android «Skaner»):
   - сканируете IMEI / штрихкод / «Aksessuar OCR» (на телефоне) или ищете в живом
     поиске на ПК;
   - вводите цену торга (`F4`), принимаете оплату (TMT, USD, смешанно или в долг)
     и нажимаете `F9` → печатаете чек.
5. Обмен / Б/У («Trade-in»): принимаете Б/У телефон на склад с оценкой и выдаёте
   новый с доплатой.
6. Закрытие дня («Maliýe»): вносите расходы, нажимаете **«🧮 Kassany sana»** для
   пересчёта наличных (и сверяете общую сумму «Jemi kassa»), делаете **Z-hasabat**
   и проверяете свежий бэкап.

5. ПОЛНЫЙ ПЕРЕЧЕНЬ ШОРТКАТОВ КЛАВИАТУРЫ (ПК)
--------------------------------------------------------------------------------

--- Глобальные (работают в любом разделе программы) ---
  Ctrl + K        — Открыть глобальный быстрый поиск (товары, штрихкоды, IMEI,
                    клиенты, чеки) с быстрой отправкой в кассу.
  Ctrl + 1        — Перейти в «Esasy panel» (Главная панель).
  Ctrl + 2        — Перейти в «Harytlar we sklad» (Товары и склад).
  Ctrl + 3        — Перейти в «Alyşlar» (Закупки).
  Ctrl + 4        — Перейти в «Satyş we kassa» (Продажи и касса).
  Ctrl + 5        — Перейти в «Trade-in» (Обмен и выкуп Б/У).
  Ctrl + 6        — Перейти в «Maliýe» (Финансы и кассы).
  Ctrl + 7        — Перейти в «Hasabatlar» (Отчёты).
  Ctrl + 8        — Перейти в «Sazlamalar» (Настройки).
  F5              — Обновить данные на текущей открытой странице.

--- В разделе «Satyş we kassa» (Касса) ---
  F2              — Открыть окно выбора товара / устройства со склада.
  F3              — Поставить курсор в строку поиска / сканера кассы.
  F4              — Быстро изменить цену продажи (торг) у выбранной строки чека.
  F9              — Пробить чек / завершить продажу.
  Delete          — Удалить выбранную строку из текущей корзины.
  Ctrl + H        — Отложить текущий чек («Çeki goý»).
  Esc             — Скрыть выпадающий список живого поиска.
  Enter           — В строке поиска кассы: мгновенно добавить товар по штрихкоду /
                    IMEI / SKU (удобно для USB-сканера).

--- В окне закупки «Täze alyş» ---
  Enter           — В поле «Ştrihkod skan et»: найти товар по штрихкоду и добавить
                    +1 шт. в закупку (либо создать новый товар с этим штрихкодом).

--- Быстрые действия мышью (двойной клик) ---
  Двойной клик по товару в «Harytlar we sklad»   — открыть карточку товара и IMEI.
  Двойной клик по IMEI в карточке товара         — открыть редактирование StockItem.
  Двойной клик по строке в журнале «Maliýe»      — открыть связанный чек или закупку.
  Двойной клик по строке в «Çekler taryhy»       — открыть детали чека / возврат / долг.

6. БЫСТРЫЕ ШПАРГАЛКИ «ЧТО ДЕЛАТЬ, ЕСЛИ…»
--------------------------------------------------------------------------------

• Как посчитать всю сумму кассы (USD + TMT вместе)?
  1) Откройте «Maliýe» — сверху сразу горит синяя строка «💰 Jemi kassa» с общей
     суммой в TMT и USD по курсу.
  2) Чтобы пересчитать реальные бумажные купюры — нажмите «🧮 Kassany sana».
  3) Для закрытия смены и PDF Z-отчёта — «🔒 Smenany ýapmak / Barlag».

• Как обнулить кассу (когда владелец забрал всю выручку) или обнулить старый долг?
  - Касса: «Maliýe» → «🧹 Kassany nolla» → выбрать TMT / USD / обе → указать причину.
  - Долг клиента или поставщика: «Maliýe» → нужная вкладка расчётов → выбрать строку:
      • «✔ Doly hasaplaş (kassa)» — закрыть долг с деньгами в кассе;
      • «🧹 Bergini nolla» — списать/обнулить долг без изменения кассы.

• Как отредактировать ошибочный IMEI, себестоимость или перенести телефон в другую модель?
  «Harytlar we sklad» → двойной клик по товару → выбрать IMEI → «✏ Saýlanan enjamy
  üýtget» (или двойной клик по IMEI). Остатки склада синхронизируются сами.

• Как убрать ненужный товар из продаж, если на складе числится остаток?
  «Harytlar we sklad» → выбрать товар → «📦 Arhiwe geçir / ♻ Dikelt». Чтобы вернуть
  назад — выберите в фильтре статуса «📦 Arhiwdäki harytlar» и нажмите ту же кнопку.

• Как быстро принять коробку аксессуаров без штрихкода (на телефоне)?
  В Android-приложении в «Kabul ediş» нажмите «Guty OCR» → наведите на надпись
  коробки → выберите существующий товар ИЛИ нажмите «Täze haryt döret (OCR-dan doldur)».
  Коробка автоматически запомнится для будущих продаж!

• Телефон не подключается к ПК через новый роутер/репитер:
  1) Если в роутере нет интернета — отключите 4G/мобильные данные на телефоне.
  2) На Windows переключите Wi-Fi на профиль «Частная сеть» (Private) и откройте
     TCP-порт 8765 в брандмауэре.
  3) Сверьте новый IP в «Sazlamalar → 📱 Mobil skaner» и отключите AP Isolation в роутере.
